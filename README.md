# Simulacre Financial Charts

A Codex skill for designing, reviewing, and exporting legible financial and macroeconomic visualizations.

Version 0.1.0 is grounded in an audit of the 53 macro indicators published by Simulacre AI in October 2026. It contains the reusable decisions, code map, pattern inventory, and compact visual reference set—not a copy of the application.

## Contents

- `skills/simulacre-financial-charts/SKILL.md` — operational guidance.
- `references/` — the pattern-to-indicator inventory and capture/export notes.
- `assets/reference-charts/` — representative PNG captures for visual calibration.

## Scope

Use this skill for line charts, signed flows, composition, seasonal comparisons, dual-axis market views, yield curves, heatmaps, instrument tables, and chart-card exports. It deliberately does not prescribe general dashboard or non-data UI design.
