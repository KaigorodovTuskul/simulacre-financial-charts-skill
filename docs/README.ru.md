# Simulacre Financial Charts — краткое руководство

[English README](../README.md) · [Исходный портал](https://simulacre-ai.ru/site/)

**Simulacre Financial Charts** — переносимый Agent Skill для построения, анализа и экспорта финансовых и макроэкономических графиков. Он помогает определить подходящий тип визуализации по смыслу показателя, а не по произвольному предпочтению библиотеки.

## Установка

```bash
npx skills add KaigorodovTuskul/simulacre-financial-charts-skill --skill simulacre-financial-charts
```

Либо скопируйте каталог `skills/simulacre-financial-charts/` целиком в папку скиллов вашего ИИ-клиента. Особенности обнаружения скиллов зависят от клиента.

## Пример

> Используй simulacre-financial-charts. Сделай график кривой доходности ОФЗ: X — срок до погашения, Y — доходность, размер точки — ликвидность. Подпиши единицы, укажи дату снимка, исключи соединение отдельных выпусков линией, проверь адаптивность и экспорт PNG.

## Что внутри

- `SKILL.md` — компактная инструкция для агента.
- `references/simulacre-v1-pattern-catalog.md` и `indicator-catalog.json` — 53 индикатора и варианты паттернов.
- `references/financial-semantics.md` — правила по датам, единицам, годовым/месячным темпам, сезонности, доходности и потокам.
- `references/design-tokens.json` — измеренные цвета экспортированных PNG, **не официальный CSS**.
- `references/capture-and-export.md` — протокол ожидания фактического рендера, скачивания и проверки изображения.
- `assets/reference-charts/` — семь избранных образцов; два из них помечены как fallback-скриншоты.

## История проверки

При первом автоматизированном экспорте 12 карточек сохранялись пустыми из-за преждевременного нажатия PNG. После ожидания заголовка и содержимого все 12 были перезахвачены. Отдельно остались две ошибки `tainted canvas` у тепловой карты и таблицы облигаций: эти файлы представлены скриншотами, а не успешными экспортами.

Для проверки структуры репозитория (Python 3.9+):

```bash
python scripts/validate.py
python -m unittest discover -s tests -v
```

Это не подтверждает качество графиков, которые сгенерирует конкретная модель. Для этого нужны сравнения на одинаковых задачах и независимая проверка.
